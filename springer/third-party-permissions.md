# Third-party material and permissions

Prepared in response to Banu Dhayalan's note of 8 September 2026 on clearing permissions
before final manuscript production.

## Summary

**There is no third-party artwork in this volume, and nothing that requires a permission
request.** Everything is either original to the author or covered by an open-source
license that permits redistribution with attribution. The one open item, an unsourced
epigraph, has been resolved by removing it.

Springer's examples of third-party material are text extracts, figures, photos, song
lyrics, poems, screenshots, logos, and trademarks. Each is addressed below.

## Figures and illustrations

All 65 captioned figures are generated by R code printed in the manuscript. There are no
reproduced, adapted, or redrawn figures from any published source, no photographs, and
no screenshots. A search of the eleven chapters found exactly one image reference, a
commented-out line in `39-controls.Rmd:1259` pointing at a local PNG that the build never
uses. It can be deleted.

Nothing to clear.

## Datasets

Every dataset used in the worked examples ships inside a CRAN package under an
open-source license, or is simulated by code in the manuscript itself. None is
proprietary and none is redistributed by the book: the reader obtains each one by
installing the relevant package.

| Dataset | Source package | Notes |
|---------|----------------|-------|
| `diamonds`, `txhousing` | ggplot2 (MIT) | Bundled example data |
| `mtcars`, `iris`, `cars` | datasets (base R, GPL) | Standard R distributions |
| `movies` | jtools (MIT) | Derived from IMDb; redistributed by the package |
| `darfur` | sensemakr (GPL-3) | Companion data to the Cinelli and Hazlett method |
| `lalonde` | MatchIt (GPL-2) | The LaLonde and Dehejia-Wahba evaluation data |
| `Mroz87` | sampleSelection (GPL-2) | Companion data for Heckman-type models |
| `PetersenCL` | sandwich (GPL-2) | Simulated panel from Petersen's clustering study |
| `PSID` | via the relevant R package | Panel Study of Income Dynamics extract |

Simulated data generated inside the chapters carries no restriction.

The chapters read no local data files. `HPC_parallel_results.csv` appears in
`44-hpc.Rmd:488` but only inside a commented-out `write.csv()` call, so there is no
external file dependency to document or ship.

Nothing to clear.

## Quotations

The eleven chapters contain forty blockquote lines. All are the author's own notes,
definitions, worked derivations, or emphasis boxes.

**Resolved.** `37-biases.Rmd` previously opened its p-Hacking section with an epigraph
attributed to Ronald Coase, "If you torture the data long enough, it will confess to
anything." It carried no source, and the attribution is a widely repeated paraphrase
rather than a verified quotation from a specific work, which sits badly against this
volume's standard that every citation carries a Crossref-verified DOI. It has been
replaced with an original line of the author's that serves the same rhetorical purpose:

> Any dataset, questioned persistently enough, will eventually agree with you.
> The work of this section is noticing when that is what happened.

`42-sensitivity-robustness.Rmd` carries a second epigraph, "Do robustness checks until
you believe the result", explicitly attributed to the author. No permission needed.

There is now no quoted third-party text anywhere in the volume.

## Software names and trademarks

The manuscript names many R packages and a few commercial products, including Apache
Spark and Tableau. These are nominative references in running text, not reproductions of
logos or marks, and need no permission.

## Author's own prior work

The eleven chapters are drawn from *A Guide on Data Analysis*, the author's own
continuously published bookdown site. Reuse of an author's own unpublished web material
in a Springer volume raises no third-party permission question, but the relationship
between the online book and the printed volume is worth confirming with Eva Hiripi,
since the online version will continue to carry the same chapters.
