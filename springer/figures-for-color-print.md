# Figures that must appear in color in the printed book

Prepared in response to Banu Dhayalan's note of 8 September 2026: "In the printed book,
figures may appear in grayscale unless otherwise agreed. If certain figures must appear
in color in the printed book, please list them separately."

The volume contains **65 captioned figures**. Every one is generated by R code in the
manuscript, so any of them can be regenerated in a different palette if that is cheaper
than color printing.

## Summary

| Category | Count | Print treatment |
|----------|-------|-----------------|
| Color carries information | 16 | Must print in color, or be redesigned |
| Color is decorative only | 6 | Grayscale is fine |
| Already monochrome | 43 | Grayscale is fine |

The 43 monochrome figures are dominated by the DAG diagrams in chapters 3 and 4, which
are drawn as black line art and lose nothing in print.

## If color printing is not agreed

Items 1 through 10, 14 and 15 are ggplot figures whose series could be separated by
linetype, point shape, or fill pattern instead of hue, at the cost of one line of code
each. Items 11, 12, 13 and 16 use a color scale as the primary encoding and would need
more substantial redesign, or a shift to faceting.

## Captions and prose that name a color

Three of these have been fixed. In each case the figure was already readable in
grayscale, because its series are separated by linetype rather than hue, so only the
wording depended on color.

| Chapter | Figure label | Was | Now |
|---------|--------------|-----|-----|
| 2. Biases | `p-value-distribution-comparison` | "Alpha=0.05 (red line)" | "Alpha=0.05 (dashed line)" |
| 7. Sensitivity | `robustness-ovb-stability` | "horizontal dashed red line ... black solid line" | "horizontal dashed line ... solid line" |
| 7. Sensitivity | `robustness-threshold-plot` | "The red line shows the threshold" | "The reference line shows the threshold" |

Two color references remain, and both are deliberate, because the figures concerned are
on the must-print-in-color list above. If Springer agrees to color for those figures the
captions are correct as they stand; if not, they need rewording along with the figures
themselves.
