# Figures that must appear in color in the printed book

Prepared in response to Banu Dhayalan's note of 8 September 2026: "In the printed book,
figures may appear in grayscale unless otherwise agreed. If certain figures must appear
in color in the printed book, please list them separately."

The volume contains **65 captioned figures**. Every one is generated by R code in the
manuscript, so any of them can be regenerated in a different palette if that is cheaper
than color printing.

**This list was cut from sixteen figures to three on 10 September 2026** by redesigning
the figures rather than paying for color. The redesigns are described at the end.

## Summary

| Category | Count | Print treatment |
|----------|-------|-----------------|
| Color carries information and cannot be redesigned cheaply | 3 | Must print in color |
| Redesigned to survive grayscale | 10 | Grayscale is fine |
| Color decorative, or already carried on a second channel | 9 | Grayscale is fine |
| Already monochrome | 43 | Grayscale is fine |

The 43 monochrome figures are dominated by the DAG diagrams in chapters 3 and 4, which
are drawn as black line art and lose nothing in print.

## Figures still requiring color

| # | Chapter | Figure label | Why it cannot be redesigned |
|---|---------|--------------|------------------------------|
| 1 | 5. Reporting | `report-amatheme-npg` | The figure exists to demonstrate the NPG journal palette applied through the custom AMA theme. In grayscale it no longer shows what the surrounding text describes. Redesigning it would defeat its purpose. |
| 2 | 7. Sensitivity | `diamonds-specr-specification-curve` | Drawn by `specr`'s own `plot()` method, which colors estimates red, gray and blue by sign internally. Changing it means either reaching into the package's returned object or abandoning its plot method. |
| 3 | 7. Sensitivity | `robustness-rdf-spec-curve` | Drawn by `plot_rdf_spec_curve()`, whose trend line runs red through black to blue. Same problem as above. |

If color is not agreed for these three, items 2 and 3 would need their plotting calls
replaced with hand-built ggplot equivalents, which is a larger change than the rest of
this work put together. Item 1 would be better dropped than printed in gray.

## Figures redesigned rather than printed in color

Each of these previously distinguished its series by hue alone. Each now carries the same
distinction on a second channel, so it reads correctly in gray.

| Chapter | Figure label | What changed |
|---------|--------------|--------------|
| 1. Endogeneity | `copula-monte-carlo` | Density outlines gain a linetype mapping |
| 1. Endogeneity | `endog-pattern-mixture-trajectories` | Linetype and point shape mapped alongside the viridis scale |
| 2. Biases | `bias-aggregation-individual-vs-neighborhood` | The 100-level neighborhood scale switched to viridis, which is monotone in luminance |
| 2. Biases | `bias-survivorship-earnings-histogram` | The two reference lines gain distinct linetypes, dashed and dotted |
| 2. Biases | `bias-publication-study-results` | Same treatment as the survivorship histogram |
| 6. EDA | `eda-price-over-time` | Faceted into six small multiples. Six noisy overlapping series were unreadable by linetype as well as by hue |
| 8. Replication | `repsynth-orig-vs-synth-hist` | Original drawn as a solid gray fill, synthetic as black hatching at 45 degrees |
| 10. HPC | `hpc-parallel-benchmark` | Bar fills switched to cividis, which is luminance-ordered. Uncaptioned, so not in the count of 65 |
| 11. Clustered inference | `clu-sim1-plot`, `clu-sim3-plot` | Linetype and point shape mapped alongside color. The 5 percent reference line changed to dot-dash so it no longer collides with the dashed cluster-robust series sitting on top of it |
| 11. Clustered inference | `clu-decision-tree` | Node fills replaced with three distinct gray levels, and border weight and style made to vary with node role |

## Captions and prose that name a color

Five have been fixed. In each case the wording was the only thing that depended on color.

| Chapter | Figure label | Was | Now |
|---------|--------------|-----|-----|
| 2. Biases | `p-value-distribution-comparison` | "Alpha=0.05 (red line)" | "Alpha=0.05 (dashed line)" |
| 2. Biases | `bias-aggregation-individual-vs-neighborhood` | "neighbourhoods colour-coded" | "neighborhoods on a luminance-ordered color scale" |
| 7. Sensitivity | `robustness-ovb-stability` | "horizontal dashed red line ... black solid line" | "horizontal dashed line ... solid line" |
| 7. Sensitivity | `robustness-threshold-plot` | "The red line shows the threshold" | "The reference line shows the threshold" |
| 8. Replication | `repsynth-orig-vs-synth-hist` | "the four original (red) and synthetic (blue) variables" | "the four original (solid fill) and synthetic (hatched) variables" |
| 11. Clustered inference | `clu-decision-tree` | "Green nodes ... orange nodes ... purple nodes" | "Light nodes with a solid border ... mid-tone nodes with a bold border ... dark nodes with a dashed border" |

One color reference remains, in the alt text of `p-hacking-pile-up-effect`, which
describes the series as gray and dark red. Alt text is read by screen readers against the
electronic edition, which is in color, so the description is accurate where it is used
and does not appear in print.

`robustness-cowplot-plotgrid` refers to "gray boxes", which survives grayscale printing
and needs no change.
